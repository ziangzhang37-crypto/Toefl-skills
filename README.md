TOEFL iBT 写作与口语教练技能
一个为 TOEFL iBT 2026 量身打造的 AI 辅导方案，不空谈“多练”，而是提供可操作、可追踪的提分路径。
实战验证：曾将学生从模考写作 4.0 / 口语 4.5（总分 5.0）提升至实考写作 5.0 / 总分 6.0。

项目背景
TOEFL iBT 2026 年题型发生了重要变化，写作部分新增了“造句”和“学术讨论”任务，口语也精简为“听后复述”和“面试”两项。在真实的辅导过程中，我们发现大多数学生的失分并不是因为“词汇不够”或“语法太差”，而是因为：

反驳只复述立场，没有击穿对方逻辑——这是学术讨论最大的坑。

邮件问候语随意，落款却极正式——社交语域（Social Conventions）经常被忽视。

同样的低级错误反复出现（如 let children to feel），纠正多次依然顽固。

练习时间分配失衡——花大量精力在已经接近满分的单项，却忽略了占写作原始分 50% 的“造句”题。

本技能正是针对这些痛点，提供一套诊断‑修正‑优先级闭环的教练框架。

核心功能
1. 官方评分标准智能打分
覆盖 写作（造句、邮件、学术讨论）和 口语（面试、复述）所有题型。

严格按照 ETS 官方 0–5 分维度（内容、句法多样性、准确性、社交语域等）逐项评分。

关键区别：评分时模拟真实评卷人的“时间压力容错”尺度——单一笔误或介词错误不会直接降档，只有结构性缺陷（逗号粘连、内容误读、重复错误）才会显著扣分。
同时提供双轨评分：一份“真实 TOEFL 等效分”，一份“更严苛的练习标准分”，避免学生被过于宽松或过于严苛的反馈误导。

2. 学术讨论反驳逻辑训练
提供 3 句压缩反驳公式，确保学生不止于“我同意/我反对”，而是真正用逻辑击穿对方的核心假设。

针对 极端归谬 和 身份/悖论类 最难话题，给出具体策略（如“拆分成两个简单句”、“用具体锚点测试抽象概念”）。

自动检测“转移话题”型反驳——即回应邻近问题而非对方原论点，这是最常见的高分杀手。

3. 邮件语域自动校准
强制检查 问候语与落款是否匹配（如 Dear Prof. 对应 Best regards，Hey 对应 Thanks）。

对“敏感/委婉”内容（如向导师提出异议）提供缓冲语模板，同时指出语法风险往往比“语气”更大。

4. 高频错误模式诊断
基于真实辅导数据，按复发频率排序（如 let/help/allow/prevent 搭配错误、逗号粘连、不可数名词复数化、间接问句结构等）。

反馈时区分“偶然失误”与“顽固模式”，并给出优先修正顺序，而非一次性列出所有问题。

5. 基于分值的提分优先级
明确告知学生“造句”题占写作原始分 50%，且为封闭式任务，提分最快——强烈建议优先训练。

当某项能力已接近上限（如听力 5.5/6），建议将时间转移到更有提升空间的领域。

如何使用
本技能可嵌入任何主流 AI 对话平台（ChatGPT、Claude、Gemini），只需将技能文档作为系统提示词，随后上传学生的写作或口语转写，AI 即会输出结构化反馈。
